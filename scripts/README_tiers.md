# 优先级学习源（日语）

## 这是什么

原来日语按**词形**（全汉字/混合/平假名/片假名）分四个侧栏 tab，每个 tab 下面再选**分卷**或**五十音**。这套切法会让你把 5805 个词平均背一遍——里面有大量人名地名（榎本、明子、放生橋）、酒类营销剧情词（試飲会、醸造）、菜名（他人丼、焼きそば），对面试毫无价值。

**这些已经全部替换掉了。** 侧栏现在是七个优先级档位，点进去直接选分卷（100 词一卷）。词形分类、分卷选择器、五十音选择器都不在导航里了。

档位按"这个词对面试值多少"切：

| 档位 | 词数 | 音频 | 说明 |
|---|---|---|---|
| 必会 | 1931 | 本地 mp3 | 第1册基础，不会就听不懂问题 |
| 普通掌握 | 911 | 本地 mp3 | 第2册核心，商务与抽象词 |
| 掌握最好 | 1183 | 本地 mp3 | 有余力再背 |
| 会不会都行 | 1022 | 本地 mp3 | 不影响面试结果 |
| 浪费时间别看 | 726 | 本地 mp3 | 人名地名·剧情词，建议直接跳过 |
| DCO专业词 | 253 | ja-JP TTS | 书里完全没有，岗位现场用语 |
| JD点名词 | 72 | ja-JP TTS | 变更管理·维护窗口·工单流程 |

前 5 档来自新标日 5805 词（已去掉 32 个跨册重复），后 2 档是书外补充。

## 重新生成

```bash
python3 scripts/build_tiers.py [分级词表目录]
```

源目录按 `TIERS_SRC` 环境变量 → 命令行参数 → `~/新标日单词/分级词表` 的顺序取。
**注意：这棵源目录树没从 Mac 搬过来**，`data/japanese/tiers/` 下已生成的 CSV 还在，
所以只有要重新生成时才需要先把源词表找回来。
输出到 `data/japanese/tiers/<档位>/<档位>_partN.csv`，每卷 100 词。

⚠️ `data/` 在 .gitignore 里，所以词表文件**不进版本控制**——换机器或清空后跑一次这个脚本即可。

## 五十音打卡板：保留了

`五十音进度` 那个打卡板（主页背景可切换的那个）**没动**，它是进度可视化，不是学习源，跟你说的"五十音不要了"不是一回事。点板上的「汉字」「混合」按钮直接开背某个音下的词，这个快捷入口也还在。

它依赖 `/japanese/kana-letters` 和 `/japanese/kana-words` 两个接口，所以这两个后端 handler 保留着。

**如果你连这个板也想删，说一声。**

## 三个现在没人调用的后端接口

`/japanese/parts`、`/japanese/words`、`/japanese/categories` 前端已经没有引用了。我**没有删**，因为：

- 它们是无害的死路由
- `/japanese/categories` 背后的 `loadJapaneseWords()` 同时也加载五十音索引，删了会连带打断打卡板
- 这批改动还没编译验证过，先不扩大爆炸半径

想清理的话单独说。

## 英语部分为什么没受影响

TTS 是唯一被英日共用的代码路径。加的 `lang` 参数**默认值就是原来的行为**：

- `lang` 为空 → `en-AU-Standard-A`，和改动前完全一致
- 缓存 key 为空 lang 时仍是裸 `text`，**已缓存的英语 mp3 全部继续有效**
- 前端英语调用点（`dictPlayTTS(txt)` 单参）走同一条退化路径

日语词对象带 `.kana` 字段，前端据此传 `lang=ja`；英语词没有这个字段，永远拿不到 ja。

其余英语后端文件（lingo/vocabulary/mistakes/tracker/progress/render/translate/cache/gcs）一个字节没动。
